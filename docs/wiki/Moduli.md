# Moduli

Respiro è organizzato in **aree** (sidebar) e **moduli** (chip o vista unica).

## Respira

Home: spazio disco, RAM, CPU e un riepilogo leggero di cosa si può fare. Nessuna scansione aggressiva all'avvio.

## Spazio

| Modulo | Cosa fa |
|--------|---------|
| **Aria** | Cache e file rigenerabili (log, download mail, ecc.) |
| **Cestino** | Svuota il Cestino di sistema |
| **Zavorra** | File ingombranti e doppioni |
| **Panorama** | Mappa visiva del disco (treemap) |

## App

| Modulo | Cosa fa |
|--------|---------|
| **Trasloco** | Disinstalla un'app e rivedi i residui prima di rimuoverli |

Trasloco chiude l'app se necessario, può chiedere la password admin per file di sistema ed estensioni camera.

## Energia

| Modulo | Cosa fa |
|--------|---------|
| **Avvio** | Elementi che partono al login |
| **Tagliando** | Manutenzione (RAM, cache DNS, log di sistema…) |
| **Guardia** | Avvio sospetto — cose da **controllare**, non "minacce" |

## Diario

| Modulo | Cosa fa |
|--------|---------|
| **Statistiche** | Spazio liberato nel tempo |
| **Registro** | File per file cosa ha fatto Respiro |
| **Scia** | Timeline visiva delle operazioni |

## Menu bar

Icona nella barra dei menu: spazio libero, RAM, CPU, apri la finestra principale.
